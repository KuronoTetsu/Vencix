# Vencix

Projeto Vencix com frontend e backend separados.

## Estrutura

- `vencix-frontend/`: páginas e scripts da interface.
- `vencix-backend/`: API Flask, modelos, migrações e testes.

## Backend

Consulte [`vencix-backend/README.md`](vencix-backend/README.md) para as instruções de configuração e execução da API.
